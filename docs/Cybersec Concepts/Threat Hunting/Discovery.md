# Discovery

Here are some examples to look for malicious activity for discovery. Elastic stack is used for hunting and the example queries are in KQL language but the principle remains the same if there is another system in use.

## Host Reconnaissance

Process creations (Sysmon Event ID 1) generated by these command line tools:

```
winlog.event_id: 1 AND process.name: (whoami.exe OR hostname.exe OR net.exe OR systeminfo.exe OR ipconfig.exe OR netstat.exe OR tasklist.exe)
```

Useful fields to look at for example:
- host.name
- user.name
- process.parent.command_line
- process.command_line

## Internal Network Scanning

All internal network connections to well-known ports:

```
source.ip: 10.0.0.0/8 AND destination.ip: 10.0.0.0/8 AND destination.port < 1024
```

Info on process that initiated the network connections, specifying the source and destination address:

```
winlog.event_id: 3 AND source.ip: <SourceIP> AND destination.ip: <DestIP> AND destination.port < 1024
```

Useful fields to look at for example:
- host.name
- user.name
- process.name
- destination.port

## Active Directory Enumeration

Processes that initiated an LDAP network connection (port 389 for LDAP and port 636 for LDAP over SSL):

```
winlog.event_id: 3 AND source.ip: 10.0.0.0/8 AND destination.ip: 10.0.0.0/8 AND destination.port: (389 OR 636) AND NOT process.name: mmc.exe
```

Excluded mmc.exe from the query since this process typically generates benign LDAP connections

Useful fields to look at for example:
- host.name
- user.name
- process.name
- destination.port
